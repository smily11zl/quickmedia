## 功能

### 1. 排序修复
- 4 种搜索模式统一排序
- 语义/综合模式默认按分数排序
- 新增"相关性"排序项（仅语义/综合模式显示）

### 2. 热度排序
- 新增 `view_count`（详情打开次数）+ `open_count`（原文件打开次数）
- 合并为"热度"排序项
- 仅 Web UI 计数

### 3. 详情页原图缩略图
- 点素材进详情页时生成原图质量缩略图
- 列表页保留低分辨率缩略图不变
