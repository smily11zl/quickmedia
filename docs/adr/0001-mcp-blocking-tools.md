# 0001 — MCP 分析工具使用阻塞模式

V14 为 MCP server 新增两个 AI 分析工具，均使用阻塞模式等待完成：

- `analyze_append_node` — 单节点分析追加（30s 超时）
- `run_aggregation` — 全量/追加/全量追加聚合（300s 超时）

与大多数 MCP 工具"立即返回"的惯例不同，这两个工具等待 AI 分析完成才返回结果。

**为何不异步：** 用户偏好对话中直接拿到结果——Agent 调工具后立刻知道分析完成了什么，
不需要二次查询状态。
**代价：** Agent 调用期间被阻塞，聚合任务素材量大时可能等待较久。
**备选方案：** 异步返回任务 ID，Agent 之后可查询状态或等 WebSocket 推送。
