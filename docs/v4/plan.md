# QuickMedia v4 需求规划

> 基于 [PRD.md](../../PRD.md) 的需求细化。

## 需求决策

| # | 决策项 | 决策 |
|---|--------|------|
| 1 | 标签弹窗交互 | 带搜索框 + 勾选列表，点击外部关闭 |
| 2 | 日期筛选交互 | 快捷按钮（今天/本周/本月/今年）+ 自定义区间 |
| 3 | 文件格式筛选 | 同标签弹窗模式（带搜索） |
| 4 | AI 状态筛选 | 同标签弹窗模式（多选） |
| 5 | 侧边栏类型筛选 | 保留，与筛选栏条件取交集 |
| 6 | 筛选栏位置 | 搜索框下方独立一行 |
| 7 | 后端筛选方式 | API 查询参数，后端 SQL 做筛选 |
| 8 | 标签清理时机 | 启动时一次性清理 + 不再生成新标签 |
| 9 | 时长段标签 | 保留在标签系统中（短片/中片/长片） |

## 筛选参数

### API: `GET /api/assets`

| 参数 | 类型 | 说明 |
|------|------|------|
| `type` | string | 素材类型，已有 |
| `date_from` | ISO date | 创建时间起始 |
| `date_to` | ISO date | 创建时间结束 |
| `mdate_from` | ISO date | 修改时间起始 |
| `mdate_to` | ISO date | 修改时间结束 |
| `formats` | string | 逗号分隔扩展名（如 jpg,png） |
| `tags` | string | 逗号分隔 tag ID |
| `ai_status` | string | 逗号分隔状态值 |

所有参数可选，全部参数取交集。

## 标签清理规则

### 需要移除的自动标签

1. **时间标签** — 纯数字年份（如 `2026`）、YYYY-MM 格式（如 `2026-06`），source='auto'
2. **格式标签** — 纯大写字母扩展名（如 `PNG`、`MP4`、`WAV`），source='auto'
3. **类型标签** — 中文类型名（`图片`、`视频`、`音频`、`文档`），source='auto'

### 保留的自动标签

- **时长段标签** — `短片(<5min)`、`中片(5-30min)`、`长片(>30min)`，仅视频素材

### 清理时机

- `quickmedia serve` 启动时执行一次
- Scanner 扫描时不再生成需移除的标签
